DO NOT implement custom protocol schemes (e.g., manga:// or protocol.registerSchemesAsPrivileged).
This breaks the Electron/Chromium/Windows setup: it destroys Chromium's file:// storage security
context and prevents LevelDB/IndexedDB backing store initialization. Reverted on 2026-11-06.
All desktop file access MUST use the verified IPC pipeline (read-file via fs.promises.readFile).

- Keep React, TypeScript, Vite, and IndexedDB unless evidence warrants a change.
- Preserve existing header reads, lazy images, transactions, and stale-write guards
  while strengthening them; do not remove working safeguards during extraction.
- Never treat TypeScript casts as runtime validation or a timeout as cancellation.
- Do not add retries for malformed input or permission denial; bound transient
  retries by attempt count and elapsed time, and expose exhausted retries.
- Browser shutdown cannot guarantee a final asynchronous save; save continuously
  and require confirmed persistence before controlled reload/navigation actions.
- Add dependencies, workers, caches, and virtualization only for demonstrated need.
- Favor a short sequence of named task calls over long inline event handlers.
  Use map/filter/find/some/every for simple collection operations and typed
  lookups for fixed independent choices; avoid nested ternaries and dense reduce.
- Retain early-return guards and bounded loops for ordered async work, streaming,
  cancellation, backpressure, and early exits. Do not replace sequential writes
  with async forEach or unbounded Promise.all to reduce statement counts.
- NEW paths above are candidate extraction points, not a requirement to create
  every file. Split only for real reuse, a distinct lifecycle/owner, or clarity;
  avoid generic dispatchers, wrappers for trivial expressions, and new frameworks.
- UI cleanup reduces competing controls and repeated text. Preserve actionable
  errors, permission guidance, accessibility, and confirmations for data removal.
- Completion notes record implemented changes; unmarked steps remain plans.
