================================================================================
CRITICAL ARCHITECTURAL INVARIANTS [PRESERVE AT ALL COSTS]
================================================================================
1. IDENTICAL UI & WORKFLOWS ("AS IS"):
   - Keep the existing React components, Tailwind styling, Inter & Instrument Serif
     typography, custom controls, and animations identical. No visual regressions.
   - Keep all reading modes: continuous vertical scroll, single-page (LTR/RTL),
     two-page spreads, webtoon, autoplay with seconds-per-screen speed, bookmarks,
     chapter-number search, and recent reading resumption.

2. STORAGE & PERSISTENCE CONTINUITY:
   - The frontend's IndexedDB backing store (titles, chapters, progress, bookmarks,
     settings) lives inside the desktop webview's storage partition.
   - Do NOT break or wipe existing user library databases.
   - Retain localPath on Manga records for native desktop file access.

3. SINGLE INSTANCE LOCKING:
   - The desktop app MUST enforce single-instance execution (via tauri-plugin-single-instance).
   - If a second instance is launched, focus the existing window and exit immediately
     to prevent storage/LevelDB concurrency corruption.

4. SAFE NATIVE FILE ACCESS:
   - File reads must be strictly bounded: 100 MiB safety ceiling per image file.
   - Folder scanning must be depth-limited (max 64 levels) and item-limited (max 100,000 files).
   - File extensions strictly allowlisted:
     .jpg, .jpeg, .png, .webp, .avif, .gif, .bmp, .svg, .ico, .heic, .heif, .tif, .tiff, .jxl.
   - Ignore junk/hidden directories: .git, .svn, .hg, node_modules, $recycle.bin, system volume information.

5. DESKTOP WINDOW & INPUT CONTAINMENT:
   - Window state (x, y, width, height, maximized) must persist in app configuration.
   - Coordinates must be validated against active monitors to avoid off-screen spawn on disconnect.
   - Visual zoom must be locked to 1:1; intercept Ctrl + [+/-/0] and Ctrl+Wheel zoom.
   - Drag-and-drop must not trigger navigation away from the application.
   - External HTTP/HTTPS URLs must open in the user's default OS browser.
   - Native Windows taskbar progress feedback: indeterminate on scan start, fractional
     (0..1) during indexing, and cleared (-1) on finish.

6. LOCAL ROUTING:
   - Retain HashRouter on desktop to ensure routing operates cleanly without server-side
     or file-scheme path rewrites.
